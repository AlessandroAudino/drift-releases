Datenschutz­erklärung

Drift wird von Alessandro Audino entwickelt, einem unabhängigen Entwickler in Italien. Diese Seite erklärt in einfachen Worten, was die Drift-App und diese Website mit Informationen über dich machen. Kurz gesagt: Drift sammelt nichts über dich.

Die Drift-App

Was sie sich ansieht. Damit das Wetter auf deinen Fenstern liegen bleibt, liest Drift, wo die Fenster auf deinem Bildschirm sind und wie groß sie sind. Es liest nie Fenstertitel oder Fensterinhalte und zeichnet deinen Bildschirm nie auf und macht keine Bildschirmfotos. Diese Positionen bleiben auf deinem Computer und werden vergessen, sobald sie benutzt wurden.

Was sie speichert. Deine Einstellungen (das gewählte Wetter, deine Vorlieben, die Stadt, deren Sonnenaufgang und -untergang die Hintergründe folgen, und dein bisheriger Hintergrund, damit er zurückgeholt werden kann) werden nur auf deinem Computer gespeichert. Solange du keine Stadt gewählt hast, schätzt Drift sie anhand der Zeitzone deines Computers. Sonnenaufgang und -untergang berechnet es selbst, ohne online zu gehen. Wenn du einen Wunsch für das neue Jahr aufschreibst, bleibt auch er dort, ebenso eine kleine Zählung deines Jahres mit Drift (Tage, Wetter, geöffnete Geschenke) für den Rückblick an Silvester.

Was sie sendet. Nichts über dich. Drift hat kein Konto, keine Statistiken, keine Werbung und keine Absturzberichte.

Updates. Etwa eine Minute nach dem Start und danach alle sechs Stunden lädt Drift eine kleine Datei von seiner öffentlichen Download-Seite auf GitHub, um zu sehen, ob es eine neue Version gibt, und lädt sie gegebenenfalls von dort herunter. Wie bei jedem Besuch einer Website erhält GitHub die Internetadresse (IP) deines Computers und einige technische Grunddaten; GitHub behandelt sie nach seiner eigenen Datenschutzerklärung. Du kannst automatische Updates unter Einstellungen › Allgemein › Updates abschalten.

Einladungs­codes. Wenn du einen persönlichen Einladungs­code bekommen hast, bewahrt Drift ihn auf deinem Computer auf und nutzt ihn dort, um zu öffnen, was für diesen Code verschlossen ist: Test­versionen oder Nachrichten für dich. Beides kommt von derselben Download-Seite; mit einem Code für Nachrichten sieht Drift dort jede Viertel­stunde nach. Der Code selbst und was er öffnet, werden nirgendwohin gesendet.

Berechtigungen auf dem Mac. Wenn du Schnee auf dem Dock einschaltest, bittet macOS dich, Drift unter Bedienungshilfen zu erlauben und ihm die Steuerung von „System Events“ zu gestatten: Drift nutzt das nur, um herauszufinden, wo das Dock ist. Auch das Setzen des Hintergrundbilds kann gelegentlich nach der Berechtigung für „System Events“ fragen und nutzt sie für nichts anderes.

Diese Website

Keine Cookies, kein Tracking. Diese Website verwendet keine Cookies, keine Statistiken und keine Werbung und lädt nichts von anderen Firmen (auch keine fremden Schriften), außer von GitHub, wo sie gehostet wird.

Hosting. Die Website und die Downloads werden von GitHub (GitHub, Inc.) gehostet. Bei deinem Besuch erhält GitHub deine IP-Adresse und die üblichen technischen Angaben deines Browsers, um die Seiten auszuliefern und den Dienst sicher zu halten. Siehe die Datenschutzerklärung von GitHub.

Download-Seite. Um die neueste Version anzuzeigen, fragt die Download-Seite bei GitHub eine kleine Datei ab, in der sie steht.

Deine Auswahl. Wenn du eine Sprache oder ein Wetter wählst, merkt sich dein Browser das auf deinem Gerät (in seinem lokalen Speicher). Es wird nirgendwohin gesendet.

Wenn du mir schreibst

Wenn du an E-Mail-Adresse folgt bald schreibst, werden deine Nachricht und deine Adresse nur verwendet, um dir zu antworten, und gelöscht, wenn sie nicht mehr gebraucht werden.

Deine Rechte

Nach den Datenschutzregeln der EU (DSGVO) kannst du fragen, welche Informationen über dich gespeichert sind, und sie berichtigen oder löschen lassen. Da Drift und diese Website keine personen­bezogenen Daten erheben, gibt es meist nichts herauszugeben, aber du kannst jederzeit unter E-Mail-Adresse folgt bald nachfragen. Du kannst dich auch bei der italienischen Datenschutzbehörde beschweren, dem Garante per la protezione dei dati personali.

Änderungen

Falls Drift einmal eine Funktion bekommt, die Informationen sendet (zum Beispiel das echte Wetter deiner Stadt), bleibt sie ausgeschaltet, bis du sie einschaltest, und diese Seite wird vorher aktualisiert.
