如何安装

在 Mac 上

在 Mac 上

  1. 打开你下载的文件，把 Drift 拖到 应用程序 文件夹。
  2. 从“应用程序”打开 Drift。它待在屏幕顶部的菜单栏里：点按它的图标即可选择天气或打开设置。

如果 Mac 第一次阻止了 Drift

抢先体验版本还没有在 Apple 注册，所以第一次打开 Drift 时 macOS 会先询问你。具体怎么做取决于提示内容：

“Apple 无法验证 Drift 是否包含恶意软件”或“无法打开 Drift”

点按 完成。打开 系统设置 › 隐私与安全性 并向下滚动。在 已阻止使用“Drift” 旁边点按 仍要打开，输入你的密码，然后点按 打开。

“Drift 已损坏，无法打开”

这个应用没有问题：对于没有在 Apple 注册的应用，macOS 就是这样提示的。点按 取消（不要点 移到废纸篓）。打开 终端（应用程序 › 实用工具 › 终端），粘贴下面这一行，按下 Return 键，然后再次打开 Drift：

xattr -cr /Applications/Drift.app

它只会去掉 Drift 上“从互联网下载”的标记。只需要做一次。

在 Windows 上

在 Windows 上

  1. 打开你下载的安装程序（Drift-Setup）。Drift 会自动安装并启动。
  2. 如果出现蓝色窗口显示 Windows 已保护你的电脑，请点击 更多信息，然后点击 仍要运行。出现这个窗口是因为抢先体验版本还没有在 Microsoft 注册。
  3. Drift 待在时钟旁边的系统托盘里。如果看不到它的图标，请点击那里的小箭头。

就这样：从现在起 Drift 会自动更新，注册后的版本也会以同样的方式送达，不再有警告。
