Politique de confidentialité

Drift est créé par Alessandro Audino, un développeur indépendant en Italie. Cette page explique simplement ce que l'app Drift et ce site font des informations qui vous concernent. En bref : Drift ne collecte rien sur vous.

L'app Drift

Ce qu'elle regarde. Pour que la météo se pose sur vos fenêtres, Drift lit l'emplacement et la taille des fenêtres à l'écran. Il ne lit jamais le titre des fenêtres ni leur contenu, et n'enregistre ni ne capture jamais votre écran. Ces positions restent sur votre ordinateur et sont oubliées dès qu'elles ont servi.

Ce qu'elle conserve. Vos réglages (la météo choisie, vos préférences, la ville dont les fonds d'écran suivent le lever et le coucher du soleil, et votre fond d'écran précédent pour pouvoir le remettre) sont enregistrés uniquement sur votre ordinateur. Tant que vous n'avez pas choisi de ville, Drift la devine d'après le fuseau horaire de votre ordinateur. Il calcule lui-même le lever et le coucher du soleil, sans se connecter à Internet. Si vous écrivez un vœu pour la nouvelle année, il reste là aussi, tout comme un petit décompte de votre année avec Drift (jours, météos, cadeaux ouverts) pour le bilan affiché au Nouvel An.

Ce qu'elle envoie. Rien sur vous. Drift n'a ni compte, ni statistiques, ni publicité, ni rapports de plantage.

Mises à jour. Environ une minute après son démarrage, puis toutes les six heures, Drift télécharge un petit fichier depuis sa page de téléchargement publique sur GitHub pour voir s'il existe une nouvelle version et, si c'est le cas, la télécharge depuis cette page. Comme lors de toute visite d'un site web, GitHub reçoit l'adresse Internet (IP) de votre ordinateur et quelques informations techniques de base, qu'il traite selon sa propre déclaration de confidentialité. Vous pouvez désactiver les mises à jour automatiques dans Réglages › Général › Mises à jour.

Codes d'invitation. Si l'on vous a donné un code d'invitation personnel, Drift le conserve sur votre ordinateur et l'y utilise pour ouvrir ce qui est verrouillé pour ce code : des versions de test, ou des messages qui vous sont destinés. Les deux viennent de la même page de téléchargement ; avec un code pour des messages, Drift y regarde tous les quarts d'heure. Le code, et ce qu'il ouvre, ne sont jamais envoyés nulle part.

Autorisations sur Mac. Si vous activez la neige sur le Dock, macOS vous demande d'autoriser Drift dans Accessibilité et de le laisser contrôler « System Events » : Drift s'en sert uniquement pour savoir où se trouve le Dock. Le réglage du fond d'écran peut aussi parfois demander l'autorisation « System Events », et ne s'en sert pour rien d'autre.

Ce site

Pas de cookies, pas de pistage. Ce site n'utilise ni cookies, ni statistiques, ni publicité, et ne charge rien depuis d'autres entreprises (pas de polices externes non plus), à part GitHub, qui l'héberge.

Hébergement. Le site et les téléchargements sont hébergés par GitHub (GitHub, Inc.). Lors de votre visite, GitHub reçoit votre adresse IP et les informations techniques habituelles envoyées par votre navigateur, pour afficher les pages et sécuriser le service. Voir la déclaration de confidentialité de GitHub.

Page de téléchargement. Pour afficher la dernière version, la page de téléchargement demande à GitHub un petit fichier qui l'indique.

Vos choix. Si vous choisissez une langue ou une météo, votre navigateur s'en souvient sur votre appareil (dans son stockage local). Ce n'est jamais envoyé nulle part.

Si vous m'écrivez

Si vous écrivez à adresse e-mail bientôt disponible, votre message et votre adresse servent uniquement à vous répondre, et sont supprimés quand ils ne sont plus utiles.

Vos droits

Selon les règles européennes de protection des données (RGPD), vous pouvez demander quelles informations vous concernant sont conservées, et les faire corriger ou supprimer. Comme Drift et ce site ne collectent pas de données personnelles, il n'y a en général rien à communiquer, mais vous pouvez toujours demander à adresse e-mail bientôt disponible. Vous pouvez aussi déposer une réclamation auprès de l'autorité italienne de protection des données, le Garante per la protezione dei dati personali.

Modifications

Si Drift ajoute un jour une fonction qui envoie des informations (par exemple la météo réelle de votre ville), elle restera désactivée tant que vous ne l'aurez pas activée, et cette page sera mise à jour avant.
