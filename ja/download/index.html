Drift をダウンロード

早期アクセス期間中は無料。インストールは一度だけ。そのあとは Drift が自動でアップデートします。

自分の Mac はどちら？

左上のアップルメニューをクリックし、このMacについて を選びます。チップ: Apple M1、M2、M3 以降と表示されていれば Apple シリコン版を、プロセッサ のあとに Intel と表示されていれば Intel 版を選んでください。

インストール方法

Mac の場合

Mac の場合

  1. ダウンロードしたファイルを開き、Drift を アプリケーション フォルダへドラッグします。
  2. アプリケーションから Drift を開きます。Drift は画面上部のメニューバーにいます。アイコンをクリックすると、天気を選んだり設定を開いたりできます。

初めて開くときに Mac が Drift を止めたら

早期アクセス版はまだ Apple に登録されていないため、初めて Drift を開くときに macOS が確認を求めます。対処法はメッセージによって異なります：

「Apple は、Drift にマルウェアが含まれていないことを検証できませんでした」または「Drift は開けません」

完了 をクリックします。システム設定 › プライバシーとセキュリティ を開いて下へスクロールし、“Drift”はブロックされました の横にある このまま開く をクリックします。パスワードを入力して、開く をクリックします。

「Drift は壊れているため開けません」

アプリに問題はありません。Apple に登録されていないアプリに対して、macOS はこう表示します。キャンセル をクリックし（ゴミ箱に入れる は選ばないでください）、ターミナル（アプリケーション › ユーティリティ › ターミナル）を開いて、次の 1 行を貼り付けて return キーを押し、もう一度 Drift を開きます：

xattr -cr /Applications/Drift.app

Drift から「インターネットからダウンロードした」という印を外すだけです。必要なのは一度だけです。

Windows の場合

Windows の場合

  1. ダウンロードしたインストーラ（Drift-Setup）を開きます。Drift が自動でインストールされ、起動します。
  2. 青いウィンドウに Windows によって PC が保護されました と表示されたら、詳細情報 をクリックしてから 実行 をクリックします。早期アクセス版がまだ Microsoft に登録されていないために表示されます。
  3. Drift は時計の横のタスクトレイにいます。アイコンが見えないときは、そこにある小さな矢印をクリックしてください。

これで完了です。今後は Drift が自動でアップデートされ、登録済みのバージョンも同じように、警告なしで届きます。
