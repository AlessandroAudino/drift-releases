プライバシーポリシー

Drift は、イタリアの個人開発者 Alessandro Audino が作っています。このページでは、Drift アプリとこのウェブサイトがあなたに関する情報をどう扱うかを、わかりやすい言葉で説明します。ひとことで言えば、Drift はあなたについて何も集めません。

Drift アプリ

見ているもの。 天気をウィンドウの上に積もらせるため、Drift は画面上のウィンドウの位置と大きさを読み取ります。ウィンドウのタイトルや中身を読むことも、画面を録画・撮影することもありません。これらの位置情報はパソコンの中にとどまり、使い終わるとすぐに忘れられます。

保存するもの。 設定（選んだ天気、各種の好み、壁紙が日の出と日の入りに合わせる都市、元に戻せるようにする以前の壁紙）は、あなたのパソコンの中だけに保存されます。都市を選ぶまでは、パソコンのタイムゾーンから Drift が推定します。日の出と日の入りは、インターネットに接続せずに Drift 自身が計算します。 新年への願いごとを書いた場合も、それはパソコンの中だけに保存されます。大晦日に表示する一年のまとめのための小さな記録（日数、天気、開けたプレゼント）も同様です。

送信するもの。 あなたに関するものは何も送りません。Drift にはアカウントも、利用統計も、広告も、クラッシュレポートもありません。

アップデート。 起動から約 1 分後と、その後 6 時間ごとに、Drift は GitHub 上の公開ダウンロードページから小さなファイルをダウンロードして新しいバージョンがあるかを確認し、あればそこからダウンロードします。ほかのウェブサイトを訪れるときと同じく、GitHub はパソコンのインターネット（IP）アドレスと基本的な技術情報を受け取り、GitHub 自身のプライバシーに関する声明に従って扱います。自動アップデートは 設定 › 一般 › アップデート でオフにできます。

招待コード。 個人用の招待コードを受け取っている場合、Drift はそのコードをあなたのパソコンに保存し、そのコード用に鍵のかかったもの（テスト版や、あなたに宛てたメッセージ）をパソコンの中で開くためだけに使います。どちらも同じダウンロードページから届きます。メッセージ用のコードがあると、Drift は15分ごとにそこを確認します。コードそのものも、それで開いた内容も、どこかへ送られることはありません。

Mac での許可。 「Dock に雪を積もらせる」をオンにすると、macOS からアクセシビリティで Drift を許可し、“System Events”の制御を許可するよう求められます。Drift はこれを Dock の位置を知るためだけに使います。壁紙を設定するときにも“System Events”の許可を求められることがありますが、ほかの目的には使いません。

このウェブサイト

Cookie なし、トラッキングなし。 このウェブサイトは Cookie も利用統計も広告も使わず、ホスティングしている GitHub 以外のほかの企業からは何も読み込みません（外部フォントも使いません）。

ホスティング。 ウェブサイトとダウンロードは GitHub（GitHub, Inc.）がホスティングしています。訪問すると、ページを届けてサービスを安全に保つために、GitHub はあなたの IP アドレスとブラウザが通常送る技術情報を受け取ります。GitHub のプライバシーに関する声明をご覧ください。

ダウンロードページ。 最新バージョンを表示するため、ダウンロードページはバージョン名が書かれた小さなファイルを GitHub に問い合わせます。

あなたの選択。 言語や天気を選ぶと、ブラウザがそれをあなたの端末（ブラウザのローカルストレージ）に記憶します。どこかへ送られることはありません。

連絡をいただいた場合

メールアドレスは準備中です にメールをいただいた場合、メッセージとアドレスは返信のためだけに使い、不要になった時点で削除します。

あなたの権利

EU のデータ保護規則（GDPR）に基づき、あなたは自分に関してどんな情報が保存されているかを問い合わせ、その訂正や削除を求めることができます。Drift とこのウェブサイトは個人情報を集めていないため、通常お渡しできるものはありませんが、いつでも メールアドレスは準備中です にお問い合わせいただけます。また、イタリアのデータ保護機関である Garante per la protezione dei dati personali に苦情を申し立てることもできます。

変更について

将来、Drift に情報を送信する機能（たとえば、あなたの都市の実際の天気）が加わる場合、その機能はあなたがオンにするまでオフのままとなり、このページも先に更新します。
